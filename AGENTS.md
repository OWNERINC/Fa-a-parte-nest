# Codex Guide: faca_parte_nest

## Project

Static landing page for the NEST campaign, inspired by the visual identity of the reference site but using original NEST copy and local assets.

## Main Areas

- `index.html`: landing page structure.
- `styles.css`: visual system and responsive layout.
- `script.js`: lightweight visual interactions.
- `assets/copys/`: user-provided copy/reference text.
- `assets/logos/`: vector logos.
- `assets/images/`: photos and still images.
- `assets/videos/`: local videos.
- `assets/icons/`: SVG/PNG icons.

## Rules

- Use the user's copy files as the source of truth for content.
- Keep the reference website as visual inspiration only; do not copy WordPress/Elementor backend code.
- Keep the form visual-only until the user defines the destination.
- Prefer local assets from `assets/` over remote URLs.
- Do not deploy unless explicitly requested.

## Verification

- Check desktop and mobile layout after visual changes.
- Verify all local asset paths before final handoff.
