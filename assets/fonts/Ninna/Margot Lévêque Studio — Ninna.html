Ninna is a Roman display font that blends historical forms with contemporary design. It features a set of classical characters and beautifully ornate swash alternates, each one inspired by the Decorative Arts. Designed by Margot Lévêque and expertly produced and developed with the help of Fanny Hamelin, Ninna was created between 2019 and 2022. This font is available in one weight and style.
